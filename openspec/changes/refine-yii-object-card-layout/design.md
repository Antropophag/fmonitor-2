## Context

См. `proposal.md`. Текущая Yii2-карточка уже получает необходимые read models, но выводит их последовательными секциями. Производственный UI обязан потреблять публичные exports `../shlz-ui`; `rapid-pilot/` не является зависимостью и будет удалён.

## Goals / Non-Goals

**Goals:**

- Перестроить только presentation-слой существующих GET-экранов и сохранить все capability checks.
- Использовать штатные Tabs и Document Row, семантические цвета, поверхности и типографику `shlz-ui`.
- Сохранить адаптивность, клавиатурную навигацию и читаемое отсутствие данных.

**Non-Goals:**

- Не менять доменную модель, БД, команды, импорт, маршруты, permissions или аудит.
- Не переносить PHP/CSS/JS из `rapid-pilot/` и не добавлять туда код.
- Не менять кадровые снимки документов: запрещается только их пользовательский вывод вне справочника.
- Не создавать новые факты готовности: показываются только уже доступные значения проекции.

## Decisions

1. Карточка остаётся серверно отрисованным Yii2 view. Таб-панели находятся в исходном HTML, а публичный behavior `shlz-ui` подключается через production asset; без JavaScript первая панель остаётся доступной. Альтернатива с отдельными маршрутами отвергнута: она разрушает согласованную компактную рабочую область.
2. Паспорт и рабочая область — две белые application surfaces на сером page surface. Внутри рабочей области применяются разделители и тематические строки, а не вложенные карточки. Это сохраняет композиционную лёгкость без отклонения от токенов.
3. Видимые сведения монтажника формируются из уже доступных полей, но view намеренно не выводит `position` и provenance. Persistence owner и read models не меняются.
4. Документы маппятся на публичный `shlz-document-row`; тип выбирается безопасно по расширению URL/имени с generic fallback. URL и правила доступа остаются прежними.
5. Готовность и оборудование читаются только из существующей object-details projection. Отсутствующее значение отображается как неизвестное; view не выводит вычисленное утверждение «Готов», если такого факта нет.
6. Паспорт показывает только устойчивые технические характеристики. `paired` исключается как рабочая очередность; утверждённый справочный код скорости `44` отображается как `1,0` м/с. Неизвестные числовые справочные коды не выводятся пользователю.

## Risks / Trade-offs

- [Часть legacy-проекции может не иметь табельного номера или кадрового статуса] → показывать только доступные значения и явное нейтральное отсутствие, не возвращать должность как fallback.
- [Много форматов технических ссылок] → ограниченный безопасный mapper известных расширений плюс generic icon.
- [Tabs могут ухудшить deep-linking] → URL persistence не входит в публичный Tabs contract; первая панель детерминирована, клавиатурный контракт обязателен.
- [Изменение CSS заденет соседние экраны] → новые правила ограничить корнем карточки; общие `.shlz-*` компоненты не переопределять.

## Migration Plan

Изменение не требует миграции данных. Развёртывание заменяет view/assets; rollback возвращает предыдущие файлы без преобразования состояния. Architecture-check impact ограничен UI assets и существующими Yii2 routes.
