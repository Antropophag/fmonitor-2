## Why

Список экономики ОТиЗ загружает все объекты и их прогресс, затем фильтрует строки в браузере. #17 требует ограниченную серверную страницу при росте до десятков тысяч объектов.

## What Changes

- Срез `OTIZ-OBJECT-REGISTER-PAGING-001`: сотрудник с `otiz.manage` читает страницу через публичный `FMonitor2\Otiz\ObjectRegister::read(actorId, query)`; HTTP сохраняет текущий UI.
- Поиск по регномеру/адресу, состояние и стабильная сортировка применяются до SQL LIMIT; прогресс загружается только для выбранной страницы.
- Глобальная финансовая сводка сохраняет прежнюю область и значения независимо от фильтров и страницы.
- Навигация сохраняет параметры, смена фильтра начинает первую страницу; удаляется браузерная фильтрация полностью загруженного набора.
- Проверки и замеры на30 000 синтетических объектов в отдельной БД, независимые reviews и полный CI.

## Capabilities

### New Capabilities

- `otiz/object-register-pagination`: ограниченная серверная страница экономики объектов с общими итогами.

### Modified Capabilities

Нет.
