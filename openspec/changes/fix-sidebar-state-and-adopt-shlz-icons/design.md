## Context

См. `proposal.md`. Общий shell отдаёт `<details open>` как безопасный server/no-JS fallback, а текущий модуль `navigation.js` читает `localStorage` в конце body. Поэтому закрытие происходит после первой раскладки. Иконки основного Yii-меню уже закрепляются локально из публичного `@shlz/icons`, но календарь использует иконку объектов, а часть близких календарных действий содержит ручной SVG.

Соседний рабочий checkout `../shlz-ui` содержит конфликтный WIP и не является допустимым входом. Источник для новых закреплённых активов — воспроизводимый публичный `dist`, собранный в чистом временном worktree из точного `shlz-ui origin/main`.

## Goals / Non-Goals

**Goals:**

- сохранить раскрытый server/no-JS fallback и убрать post-paint коррекцию сохранённого состояния;
- покрыть реальный порядок загрузки быстрым browser/DOM feedback loop;
- заменить только однозначные случаи, подтверждённые публичным каталогом;
- сохранить единого владельца основной навигации `MainNavigation` и read-only характер UI.

**Non-Goals:**

- не вводить клиентский router или пользовательский серверный профиль;
- не изменять `shlz-ui`, его каталог или release-процесс;
- не считать логотип, диаграммы данных и структурные SVG пиктограммами действий;
- не расширять аудит на архивные прототипы и не добавлять новую доменную логику в `rapid-pilot`.

## Decisions

1. **Ранний минимальный bootstrap в head.** Неблокирующий inline-скрипт до загрузки stylesheet читает только известный ключ и ставит маркер свёрнутого состояния на корневой элемент. Серверная разметка остаётся `open`, а CSS по маркеру сразу отображает компактную геометрию до того, как основной модуль синхронизирует DOM. Альтернатива — cookies/серверный профиль — добавляет writer, privacy и concurrency semantics ради локальной настройки; поздний скрипт не устраняет first paint.
2. **Явная фаза hydration без transition.** До завершения синхронизации CSS подавляет только переход ширины shell; после неё обычная интерактивная анимация сохраняется. Альтернатива — отключить transition всегда — ухудшает обратную связь при ручном переключении.
3. **Один ключ и один исполнитель.** Ранний bootstrap только публикует начальный маркер. Существующий `navigation.js` остаётся владельцем `<details>`, текста, ARIA и записи `localStorage`, затем удаляет маркер и ставит признак готовности.
4. **Pinned public exports.** SVG копируются из чисто собранного `packages/icons/dist/icons/*` и проверяются по DOM-геометрии против того же публичного export. Для календаря выбирается sidebar-вариант в основном меню; interface-вариант допустим для action/status compositions, если аудит подтверждает размер и семантику.
5. **Ограниченный аудит.** Инвентаризация классифицирует 29 исполняемых SVG-вхождений baseline и отдельно декларации общего `MainNavigation`: brand/data graphics, уже shlz-backed, однозначно заменяемые и без точного публичного аналога. Реализация меняет только вторую/третью группы, не угадывает соответствия.

Owning module: `app/YiiRuntime` shell/assets; `rapid-pilot` остаётся адаптером существующих композиций. Persistence owner отсутствует: используется только browser localStorage, доменные writers не затрагиваются. Ожидаемое влияние architecture-check — отсутствует за пределами проверки публичного asset boundary.

## Risks / Trade-offs

- [Inline bootstrap может нарушить CSP] → использовать nonce-aware Yii registration либо внешний ранний asset, совместимый с текущим CSP-контрактом, и проверить реальный response.
- [CSS-маркер и `<details>` разойдутся] → основной модуль синхронизирует оба состояния в одном tick и тест проверяет cleanup.
- [Новый календарный SVG ещё не опубликован в старом локальном dist] → строить публичный dist только из чистого точного `shlz-ui origin/main`, фиксировать upstream commit и geometry digest; не читать конфликтный checkout.
- [Массовая замена ухудшит семантику] → заменять только точные соответствия и хранить перечень оставленных случаев с причиной.

## Migration Plan

Срез не требует БД или конфигурационной миграции. Deploy заменяет статические assets и серверный shell атомарно. Rollback — откат коммита; существующее значение localStorage совместимо в обе стороны.
