## Purpose

Определяет наблюдаемый контракт read-only справочника монтажников после переноса публичного маршрута в целевой Yii2 runtime.

## ADDED Requirements

### Requirement: Публичный справочник сохраняет каталог и проекции закреплений
Система SHALL обслуживать `GET /pilot/installers` как серверную HTML-страницу: показывать только доставленные записи кадрового каталога, их ФИО, табельный номер, должность, статус, время источника и действующие на текущую Moscow-дату закрепления из последней зарегистрированной версии распоряжения. Результат SHALL сортироваться по ФИО и устойчивому идентификатору, содержать не более 50 строк на странице и не изменять доменные, кадровые или audit facts.

#### Scenario: Каталог с действующими закреплениями
- **WHEN** авторизованный пользователь с `installers.read` открывает каталог, содержащий 125 доставленных записей и действующие закрепления первых пяти монтажников
- **THEN** первая страница содержит 50 строк, третья — 25, summary сообщает 125 записей и 3 страницы, а ссылки закреплений ведут в соответствующие карточки объектов

#### Scenario: Пустой доставленный каталог
- **WHEN** доступ разрешён, но доставленных кадровых записей нет
- **THEN** ответ имеет статус 200, показывает отдельное состояние «Каталог монтажников пока не загружен» и не создаёт данные

### Requirement: Поиск, фильтры и пагинация совместимы с действующим маршрутом
Система SHALL принимать `q` длиной не более 120 Unicode characters, `status` только из `employed|dismissed|empty`, `availability` только из `assigned|free|empty` и положительную decimal `page`. Поиск SHALL находить подстроку ФИО или цифровую часть табельного номера; фильтры SHALL комбинироваться, а ссылки пагинации SHALL сохранять активные фильтры.

#### Scenario: Комбинированный фильтр
- **WHEN** пользователь запрашивает `status=dismissed&availability=free&page=1` на принятом примере из 125 записей
- **THEN** ответ показывает ровно 40 совпадений и отражает выбранные фильтры в HTML

#### Scenario: Невалидный фильтр
- **WHEN** query содержит недопустимый status/availability, неположительную page, массив вместо scalar или строку поиска длиннее 120 characters
- **THEN** система возвращает 400 без чтения как допустимого результата и без каких-либо новых facts

### Requirement: Доступ и HTTP-границы закрыты по умолчанию
Система SHALL требовать действительную Yii-сессию и точный grant `installers.read`. Неаутентифицированный browser request SHALL перейти к `/pilot/login` с сохранённым безопасным return URL, а активный пользователь без grant SHALL получить 403. Методы кроме GET/HEAD SHALL получить 405 с `Allow: GET, HEAD`; HEAD SHALL повторять status/headers GET и иметь пустое тело.

#### Scenario: Разрешённый reader
- **WHEN** активный пользователь с точным grant выполняет GET и HEAD
- **THEN** GET возвращает 200 HTML, HEAD возвращает те же существенные headers без body, а кадровые и процессные facts byte-equivalent до и после

#### Scenario: Отказ в доступе и неверный метод
- **WHEN** запрос выполняет anonymous, grant-only reader без `installers.read` либо клиент использует POST
- **THEN** система соответственно возвращает login redirect, 403 либо 405 и не раскрывает содержимое каталога

### Requirement: Сбои безопасны, а runtime независим от rapid-pilot
Система SHALL возвращать sanitized 503 с `Retry-After: 60`, если обязательная schema, данные, конфигурация или read connection недоступны/некорректны. Обработка `/pilot/installers` SHALL использовать явно настроенные DB/prefix и SHALL NOT выполнять DDL, bootstrap, import или загружать rapid-pilot runtime. HTML SHALL экранировать все кадровые и объектные строки, использовать существующие Yii assets и оставаться доступным без горизонтального overflow на ширине 390px.

#### Scenario: Сбой чтения
- **WHEN** обязательная workforce/process schema отсутствует либо read model получает некорректную обязательную строку
- **THEN** клиент получает только sanitized 503 и Retry-After, без SQL/path/config/person details и без попытки repair

#### Scenario: Реальный browser и runtime closure
- **WHEN** пользователь ищет, фильтрует и перелистывает каталог в desktop и 390px browser
- **THEN** поля, строки, ссылки, keyboard labels и pagination доступны, console/page errors отсутствуют, HTML экранирован, а load trace маршрута не содержит production include/require из `rapid-pilot`
