## Context

117 записей unit (PHP и Node), 120 DB; characterization и E2E заданы отдельно. Unit пока содержит также инфраструктурные проверки.

## Goals / Non-Goals

Единый явный каталог без исполнения тестов при list; сохранение состава и порядка; видимость длительностей. Не ускорять CI за счёт пропуска гарантий. Это законченный первый срез, не закрытие всей #25.

## Decisions

Владелец — tools/verification/run.sh; каталог suites.tsv содержит group, runtime, path. Bash 3.2 сохраняется, list не вызывает интерпретаторы или rg. Допустимы PHP, Node, Python3. Проверяем уникальность пары group/path, существование файлов и покрытие двух PHP-каталогов и Node tests/Verification. Повтор одного пути в разных группах пока допустим для совместимости E2E. Неизвестный файл останавливает runner, так что проверка не теряется. Characterization сохраняет исходный порядок; unit PHP затем Node. Обычные runtime зависимости прежние. Длительность — целые секунды Bash SECONDS без дополнительного процесса; это грубая метрика, не benchmark субсекундных тестов. Вывод VERIFY_TIMING содержит suite, runtime, file, seconds, exit. Листинг не выводит timing. Каталог не владеет предметными фактами; rapid-pilot остаётся только вызываемым oracle.

## Risks / Trade-offs

Новые тесты требуют регистрации; явная ошибка объясняет действие. Старое автоматическое обнаружение заменяется проверяемой регистрацией, гарантия отсутствия пропуска сохраняется. Характеризационные Python-тесты сохраняют fail-fast; PHP и unit — сбор отказов. Рекурсивные дочерние запуски отражаются в длительности родителя.

## Migration Plan

Сверить unit/db до и после побайтно, отдельно исходный characterization/e2e. RED и независимый Gate3 до реализации; focused GREEN и Gate5. Полный production gate не заявлять. Следующий срез — сокращение E2E и матрица CI после согласования.
