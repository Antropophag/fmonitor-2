## Purpose

Определяет состав рабочей очереди стройконтроля так, чтобы она показывала только дела, где участие инженера ещё требуется, и не превращала документарное закрытие в рабочую задачу стройконтроля.

## ADDED Requirements

### Requirement: Документарное закрытие отсутствует в рабочей очереди стройконтроля

Система SHALL исключать из результата `GET /pilot/construction-control` открытое
монтажное дело, как только для него принят append-only факт акта ПТО. Наличие или
отсутствие декларации не меняет это исключение: после акта ПТО следующее действие
принадлежит документарному закрытию, а не стройконтролю.

#### Scenario: Дело с актом ПТО не отображается

- **WHEN** уполномоченный пользователь открывает очередь, содержащую одно рабочее дело без completion facts, одно дело только с `pto_act` и одно дело с `pto_act` и `declaration`
- **THEN** HTTP-ответ 200 содержит только дело без `pto_act`, а общее число и пагинация рассчитаны по тому же отфильтрованному составу

#### Scenario: Обновление отражает переход без изменения истории

- **WHEN** для ранее отображавшегося рабочего дела принят факт `pto_act` и пользователь повторно запрашивает очередь
- **THEN** дело отсутствует в новом ответе, а чтение очереди не изменяет и не удаляет дело, completion facts, checklist operations или process events

### Requirement: Допуск и безопасные отказы сохраняются

Система MUST сохранять действующий Yii2 session/RBAC contract очереди и не
раскрывать данные неуполномоченному пользователю. Изменение состава выдачи не
должно создавать новый state-changing seam, retry или concurrency behavior.

#### Scenario: Пользователь без полномочия не получает очередь

- **WHEN** активный пользователь без `construction_control.read` запрашивает очередь
- **THEN** система возвращает HTTP 403 без процессных записей и без раскрытия состава очереди

#### Scenario: Повторное чтение детерминировано

- **WHEN** уполномоченный пользователь повторяет один и тот же GET без изменения фактов
- **THEN** состав, общее число и границы страниц остаются одинаковыми, а история остаётся неизменной
