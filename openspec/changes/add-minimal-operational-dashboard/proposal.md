## Why

Руководителю и сотруднику ФКР сейчас приходится просматривать реестр объектов построчно, чтобы понять общий объём текущей работы и найти ближайшие проблемные объекты. Нужен небольшой read-only экран на реальных данных приложения, который можно показать заказчику и использовать как предметный прототип для сбора следующих требований.

## What Changes

- Добавить доступный пользователям с `objects.read` операционный дашборд на публичном Yii-маршруте и включить его в основную навигацию.
- Показать на дату среза небольшой набор однозначных показателей: всего доступных объектов, объекты в активном монтаже, объекты с просроченным плановым окончанием и ближайшие плановые начала.
- Дать переходы из показателей и коротких списков в соответствующий отфильтрованный реестр либо карточку объекта; область данных каждого результата совпадает с областью доступа пользователя.
- Рассчитывать агрегаты и ограниченные списки на сервере без загрузки полного реестра в PHP или браузер; экран не создаёт и не изменяет предметные факты.
- Использовать только публичные композиции `shlz-ui`, включая Dashboard, Chart Widget, status/link/button и empty-state; не добавлять UI- или chart-зависимости.
- Явно показывать дату среза, отсутствие данных и безопасную ошибку загрузки; сохранить работоспособность на узком экране.
- Подготовить короткий сценарий демонстрации и вопросы заказчику о следующих решениях и разрезах.

## Capabilities

### New Capabilities

- `ui/minimal-operational-dashboard`: read-only операционная сводка по доступным объектам монтажа, её маршруты, показатели, состояния и переходы.

### Modified Capabilities

- Нет.

## Impact

- Actor: активный пользователь с `objects.read`; пользователи без полномочия не видят пункт навигации и не получают данные маршрута.
- Source oracle: canonical installation cases и существующие Yii-проекции статуса/прогресса; дата среза — календарная дата `Europe/Moscow` на момент запроса.
- Target public seam: `GET|HEAD /pilot/dashboard`, основная Yii-навигация и ссылки в существующий `/pilot/objects`/карточки.
- Затрагиваются Yii controller/view/navigation, новый bounded read model, CSS-подключение публичных экспортов `../shlz-ui`, focused HTTP/browser tests, документация демонстрации.
- Release value: заказчик получает рабочий минимальный обзор вместо макета и может конкретизировать следующие показатели на основании реального интерфейса.
- Non-goals: новые domain facts/DDL/permissions, финансовая аналитика ОТиЗ, конструктор отчётов, произвольные периоды, пользовательская настройка/сохранение виджетов, тренды без исторического основания, сторонние chart-библиотеки и изменения `rapid-pilot/`.
