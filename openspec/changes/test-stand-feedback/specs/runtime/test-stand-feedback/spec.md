## Purpose

Обратная связь тестового стенда сохраняет описание и минимальный безопасный контекст, позволяя уполномоченному сотруднику разбирать сообщения без внешних отправок.

## ADDED Requirements

### Requirement: Minimal feedback journal

Система SHALL исполнять нормативный контракт `specs/FEEDBACK-001.md` (A1–A7) через единый application seam с существующей авторизацией и append-only историей.

#### Scenario: Submit and review
- **WHEN** активный пользователь отправляет описание, а уполномоченный сотрудник добавляет результат разбора
- **THEN** сохраняются только разрешённый контекст и неизменяемые записи по A1–A3/A5; повтор, concurrency и сбои подчиняются A4, UI — A6, persistence и восстановление — A7.
