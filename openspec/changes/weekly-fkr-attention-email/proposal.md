## Why

Руководителям ФКР нужен один воспроизводимый еженедельный обзор планов, подтверждённого прогресса и объектов, требующих внимания, без ручной сборки сводки и без выдачи неизвестных данных за благополучное состояние. Владелец поручил реализовать GitHub issue №11 и разрешил использовать SMTP и тестовый ящик из соседнего `k2` только как внешний эксплуатационный источник конфигурации.

## What Changes

- Добавляется автоматический запуск каждый понедельник в 09:00 `Europe/Moscow` с периодами: текущая неделя понедельник–воскресенье и предыдущая завершённая неделя.
- Для каждого активного пользователя с ролью «Руководитель ФКР», `objects.read` и валидным email формируется отдельный HTML+text отчёт по полному общему набору объектов с пятью разделами: плановые открытия, плановые закрытия, недельный прогресс, фактическая просрочка и «Обратить внимание».
- Раздел «Обратить внимание» не называется просрочкой. В него попадают объекты со сроком в ближайшие семь календарных дней и зафиксированным препятствием либо недостаточной подтверждённой готовностью; недостаток исходных данных явно показывается как «Недостаточно данных для оценки».
- Недельный прогресс строится по подтверждённой истории на границах периода, учитывает исправления и раздельно показывает выполнение работ (85%) и документарное закрытие (15%).
- Генерация отчёта является read-only проекцией. Планирование, durable job, outbox и доставка сохраняют технические факты идемпотентности/попыток, но не изменяют предметную историю монтажных дел.
- Успешная доставка одному получателю за одну отчётную неделю не повторяется; временная ошибка допускает повтор, постоянная фиксируется. SMTP задаётся только переменными окружения, секреты не попадают в репозиторий, письмо или логи.
- Добавляются readiness-проверка конфигурации, тестовый безопасный recipient override и эксплуатационная документация для SMTP-профиля `k2-mailer` без сохранения его секрета.
- HTML-письмо оформляется в визуальном языке FMonitor как image-free Outlook-safe table layout: без картинок и внешних ресурсов, с inline CSS и читаемым web/narrow fallback.

## Capabilities

### New Capabilities

- `weekly-fkr-attention-email`: недельный scoped отчёт руководителю ФКР, календарные границы, пять разделов, правила внимания, идемпотентный durable delivery и безопасная SMTP-конфигурация.

### Modified Capabilities

Нет.

## Impact

- Actor: активный пользователь роли «Руководитель ФКР»; source oracle: канонические native-факты объектов, плановых дат, подтверждённой истории прогресса, документов, нарушений и области доступа.
- Target public seams: scheduler/jobs console для запуска; application report builder для детерминированной проекции; существующие durable jobs/outbox для доставки.
- Затрагиваются `app/Jobs`, native read-модели identity/access и монтажных дел, Yii console wiring, schema migration для технической дедупликации при необходимости, compose/runtime configuration, focused tests и operations docs.
- Внешняя зависимость — SMTP-сервер, совместимый с профилем соседнего `k2`; секрет передаётся средой исполнения.
- Не входят: редактирование предметных фактов из письма, вложения, массовая копия/BCC, новые роли и permissions, изменение формулы 85/15, прогноз на основе ML, изменение карточки объекта, импорт исторических email или секретов из `k2`.
