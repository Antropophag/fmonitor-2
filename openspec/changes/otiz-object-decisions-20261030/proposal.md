## Why

ОТиЗ должен исключать монтажника из выплаты только по выбранному объекту, сохраняя его долю в резерве. Прежнее решение по работнику распространялось на весь расчёт и затрагивало другие объекты.

## What Changes

- Добавить точную область решения `объект + монтажник` с обязательной причиной отказа.
- Сохранить исторические решения без объекта как глобальные и дать точному решению приоритет только для своей пары.
- Провести область через preview, recovery, замену расчёта, XLSX и интерфейс выбора объекта.
- Добавить совместимую каноническую миграцию и recovery frontier 38.

## Capabilities

### New Capabilities

- `otiz/object-scoped-payment-decisions`: решения по выплате и резерв строго в пределах пары объект+монтажник.

### Modified Capabilities

Нет.

## Impact

Затронуты OTIZ settlement application/read projection, Yii controller/UI, workbook, каноническая миграция и recovery/readiness. Выплаченные факты и исторические решения не переписываются. Нормативный контракт: `specs/OTIZ-OBJECT-DECISIONS-20261030.md`.
