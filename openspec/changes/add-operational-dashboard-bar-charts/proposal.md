## Why

Минимальный операционный дашборд показывает отдельные числа и списки внимания, но не позволяет руководителю быстро увидеть распределение портфеля, будущие пики нагрузки и зависшие активные объекты. Согласованный с владельцем срез добавляет три наглядные столбчатые диаграммы, каждая из которых ведёт к конкретному управленческому действию.

## What Changes

- Добавить в Yii-раздел «Дашборд» три read-only диаграммы на единой дате среза: распределение объектов по этапам, плановые начала и окончания по шести календарным неделям и давность последней подтверждённой активности активных объектов.
- Сделать каждый столбец самостоятельным доступным переходом в существующий реестр с каноническим серверным фильтром; видимое значение и текстовая расшифровка не зависят только от цвета или графики.
- Рассчитывать агрегаты bounded SQL/read-model запросами из канонических текущих фактов без загрузки полного набора в PHP или DOM и без создания новой предметной таблицы, кэша либо writer seam.
- Использовать публичные Dashboard/Chart Widget и control/status/link contracts из закреплённого `shlz-ui`; сами chart marks и их семантика принадлежат приложению, без сторонней chart-зависимости.
- Сохранять честные empty/error/unknown состояния и responsive document flow на узком экране.
- Сделать change зависимым от ещё не интегрированного predecessor `add-minimal-operational-dashboard`; не копировать его реализацию и не считать его старую ветку частью текущего source.

## Capabilities

### New Capabilities

- `ui/operational-dashboard-bar-charts`: read-only операционные столбчатые диаграммы для пользователя с `objects.read`, их точные классификации, drill-down переходы, bounded вычисление и доступное responsive-представление.

### Modified Capabilities

Нет.

## Impact

- Актор: руководитель или иной активный пользователь с `objects.read`.
- Source oracle: канонические installation cases, распоряжения/applications, completion facts, checklist operations и плановые даты legacy object projection; UI-контракты — публичные exports соседнего read-only `../shlz-ui`.
- Target public seam: `GET|HEAD /pilot/dashboard` и поддерживаемые query-фильтры существующего `/pilot/objects`.
- Release value: быстрое обнаружение процессной очереди, недельных пиков и объектов без недавней подтверждённой активности.
- Затрагиваются Yii dashboard read model/controller/view, объектный реестр только в части канонических read-only фильтров, закреплённые публичные CSS assets и focused data/HTTP/browser tests.
- Не затрагиваются state-changing seams, схема и история предметных фактов, ОТиЗ-расчёты, персонализация раскладки, произвольные периоды, экспорт, real-time обновление и диаграмма нагрузки по сотрудникам.
- Predecessor `add-minimal-operational-dashboard` должен быть интегрирован или явно включён в отдельный exact-source candidate до Gate 2; пока это не выполнено, implementation slice заблокирован.
