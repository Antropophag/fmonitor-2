# ORDER-PREPARE-001-H — закрытый security-аудит отказа в доступе

- Статус: `APPROVED`
- Версия: `0.2`
- Дата: `2026-08-27`
- Родительская спецификация: [`ORDER-PREPARE-001`](ORDER-PREPARE-001.md)
- Акторы: пользователь без полномочия подготовки и системный администратор
- Командный шов: `InstallationProcess.prepareAssignmentOrder(...)`
- Шов security-аудита: `InstallationProcess.getSecurityAudit(installationObjectId, actorId)`

## 1. Цель среза

Доказать, что отклонение `FORBIDDEN` сохраняется в закрытом append-only security-аудите, не раскрывает проверку состава вызывающему пользователю и доступно для чтения системному администратору.

## 2. Роли и полномочия

- пользователь `91` аутентифицирован, но не имеет `assignment_order.prepare`;
- системный администратор `7` имеет `security_audit.read`;
- `security_audit.read` не предоставляет `assignment_order.prepare` и не позволяет изменять событие;
- обычная проекция `getInstallationObjectProcess` не является способом чтения security-аудита.

## 3. Предусловия

- объект монтажа `4512` существует;
- исходный security-аудит объекта монтажа пуст;
- серверные часы зафиксированы на `2026-08-27T10:30:00+03:00`;
- пользователь `91` отправляет пустой состав, как в Example D;
- состояние монтажного дела, состав и доступность объекта монтажа не должны проверяться или раскрываться до отказа авторизации.

## 4. Действие пользователя без полномочия

```text
prepareAssignmentOrder(
  installationObjectId: 4512,
  installerTabIds: [],
  controlEngineerUserId: null,
  actorId: 91
)
```

Команда возвращает только:

```text
{
  accepted: false,
  violations: [
    {
      code: "FORBIDDEN",
      message: "У вас нет права формировать распоряжение.",
      field: null
    }
  ]
}
```

## 5. Действие системного администратора

После отказа системный администратор вызывает:

```text
getSecurityAudit(installationObjectId: 4512, actorId: 7)
```

## 6. Наблюдаемый результат security-аудита

```text
[
  {
    type: "assignment_order_prepare_rejected",
    occurredAt: "2026-08-27T10:30:00+03:00",
    actorId: 91,
    payload: {
      reasonCodes: ["FORBIDDEN"],
      installerCount: 0,
      controlEngineerProvided: false
    }
  }
]
```

Одна отклонённая команда создаёт ровно одно событие.

## 7. Защита проекции

Если пользователь без `security_audit.read` вызывает `getSecurityAudit`, метод возвращает результат отказа той же публичной формы, что и отклонённая команда:

```text
{
  accepted: false,
  violations: [
    {
      code: "FORBIDDEN",
      message: "У вас нет права просматривать security-аудит.",
      field: null
    }
  ]
}
```

Ответ не содержит `events`, их количество или иные признаки существования security-событий. Его собственный технический аудит не входит в данный срез.

## 8. Инварианты

- авторизация `prepareAssignmentOrder` выполняется до проверки объекта монтажа, состава и каталогов;
- ответ команды не содержит `INSTALLER_REQUIRED` или `CONTROL_ENGINEER_REQUIRED`;
- security-событие не появляется в обычной процессной истории, доступной штатным ролям;
- событие доступно только через авторизованный `getSecurityAudit`;
- событие не содержит идентификаторы выбранных людей, ФИО, полное тело команды, сведения о состоянии объекта монтажа или внутренние идентификаторы хранения;
- security-аудит append-only: системный администратор не может исправить или удалить событие через этот seam;
- распоряжения, назначения, задачи, документы и legacy-проекция не меняются.

## 9. Независимое ожидаемое значение

- `FORBIDDEN` и отсутствие предметных причин заданы Example D;
- роль читателя определена владельцем продукта как системный администратор;
- время задано фиксированными серверными часами;
- нулевые признаки состава следуют из входа, не из каталогов;
- одно событие следует из правила «одна отклонённая команда — один факт аудита».

## 10. Не входит в срез

- UI системного администратора;
- поиск security-событий по всем объекта монтажам;
- экспорт, срок хранения и архивирование аудита;
- технический аудит отказа чтения security-аудита;
- DB-схема и физическое разделение журналов;
- успешное формирование распоряжения.
