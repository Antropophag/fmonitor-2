# ORDER-PREPARE-002-C — отказ при отсутствии подъезда или секции

- Статус: `APPROVED`
- Версия: `0.1`
- Дата: `2026-08-27`
- Актор: сотрудник ФКР с полномочием `assignment_order.prepare`
- Публичный командный шов: `InstallationProcess.prepareAssignmentOrder(installationObjectId, installerTabIds[], controlEngineerUserId, actorId)`
- Публичный шов наблюдения: результат команды и `InstallationProcess.getInstallationObjectProcess(installationObjectId)`

## 1. Цель среза

Не допустить подготовки распоряжения, если в снимке legacy-объекта монтажа отсутствует подъезд/секция объекта, обязательный отдельной колонкой нормативного приложения.

Срез проверяет только `installationObjectSnapshot.entrance`, источником которого в пилоте является `fm_maintable.entrance`. Контракты адреса и успешного пути остаются в `ORDER-PREPARE-002-B` и `ORDER-PREPARE-002`.

## 2. Предусловия

- авторизация и обязательный состав успешно проверены;
- объект монтажа существует, доступен и находится в `needs_assignment_order` без версии распоряжения, открытия, завершения и даты Акта ПТО;
- адрес, регистрационный номер объекта и актуальные плановые даты заполнены;
- выбран один допустимый монтажник и один допустимый инженер;
- каталоги людей и renderer доступны, но при отсутствии подъезда/секции не вызываются;
- конкурентного изменения нет.

## 3. Нормализация

Подъезд/секция считается отсутствующим, если `installationObjectSnapshot.entrance` равен `null`, пустой строке либо строке, пустой после удаления пробелов по краям. Непустое значение команда не исправляет и при успехе сохраняет как снимок адаптера.

## 4. Порядок проверки

После авторизации и проверки обязательного состава команда загружает снимок объекта монтажа. Проверка адреса выполняется раньше проверки подъезда/секции. Проверка подъезда/секции выполняется раньше каталогов людей, определения бизнес-даты, renderer и любых процессных изменений.

Полный ответ для одновременно отсутствующих реквизитов определяет `ORDER-PREPARE-002-E` после его утверждения; этот срез сохраняет одиночный ответ для `entrance`.

## 5. Наблюдаемый отказ

```text
accepted = false
violations = [
  {
    code: INSTALLATION_OBJECT_REQUIRED_DATA_MISSING,
    message: "В объекте монтажа не заполнен подъезд или секция объекта.",
    field: entrance
  }
]
```

## 6. Состояние и аудит

Версия, назначения и артефакты не создаются; `processState = needs_assignment_order`; задача `prepare_assignment_order` остаётся открытой; работы и чек-лист закрыты. Добавляется одно событие `assignment_order_prepare_rejected`:

```text
reasonCodes = [INSTALLATION_OBJECT_REQUIRED_DATA_MISSING]
missingFields = [entrance]
installerCount = 1
controlEngineerProvided = true
```

Событие также содержит `installationObjectId`, `actorId` и серверный `occurredAt`, но не значения объекта монтажа, ФИО, табельный номер либо идентификатор инженера.

## 7. Исполняемый пример A

```text
installationObjectId = 4512
installerTabIds = [1042]
controlEngineerUserId = 73
actorId = 18
now = 2026-08-27T12:05:00+03:00

address = "Москва, ул. Примерная, д. 10"
entrance = "   "
objectRegistrationNumber = "77-000123"
plannedStartDate = 2026-10-05
plannedFinishDate = 2026-12-20
ptoActDate = null
```

Ожидается точный отказ из раздела 5. Исходное состояние `needs_assignment_order` с пустыми версиями/назначениями и открытой задачей подготовки сохраняется; добавляется только событие из раздела 6 с `occurredAt = 2026-08-27T12:05:00+03:00`. Fixture запрещает обращения к каталогам людей и renderer.

## 8. Приоритеты и отказы

- `FORBIDDEN`, `INSTALLER_REQUIRED` и `CONTROL_ENGINEER_REQUIRED` имеют ранее утверждённый приоритет.
- Отсутствующий адрес имеет приоритет над отсутствующим подъездом/секцией.
- Этот срез добавляет только `INSTALLATION_OBJECT_REQUIRED_DATA_MISSING` для `field = entrance`.

## 9. Не входит в срез

- отсутствие регистрационного номера объекта и плановых дат;
- объединение нескольких отсутствующих полей;
- проверка формата или существования непустого подъезда;
- прочие отказы состояния, людей, renderer, persistence и конкурентности;
- успешная подготовка, UI и HTTP.
