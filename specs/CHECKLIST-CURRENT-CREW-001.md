# CHECKLIST-CURRENT-CREW-001

When more than one registered assignment-order version exists for an open installation case, the checklist current crew is exactly the installer snapshot of the registered order with the greatest version number.

Previously completed checklist items retain their recorded installer snapshots even when those installers are absent from the latest order.

Acceptance example: order version 1 contains installer 101; order version 2 contains only installer 202. The checklist exposes only installer 202 for new work, while an item completed before version 2 still displays installer 101.
