# YII2-SIDEBAR-STATE-ICONS-001 — стабильный сайдбар и иконки shlz-ui

## Простыми словами

Свёрнутое меню не должно на мгновение раскрываться при переходе на другую страницу. Заодно рабочие пиктограммы, для которых есть точное соответствие в публичном каталоге `shlz-ui`, должны использовать корпоративный источник; приблизительные замены запрещены.

## Нормативный контракт

Актор: любой аутентифицированный пользователь Yii pilot shell.

Публичный seam: полная загрузка разрешённой страницы `/pilot/*`, управление сворачиванием сайдбара и отрисованный HTML/SVG соответствующей рабочей композиции.

1. При сохранённом `fmonitor.sidebar.expanded=false` новая страница обязана до первого видимого кадра иметь свёрнутое состояние. Переход из серверного `open` в закрытое состояние после paint запрещён.
2. При сохранённом `true`, отсутствии значения или ошибке доступа к хранилищу серверный раскрытый fallback сохраняется.
3. Без JavaScript навигация остаётся раскрытой и работоспособной.
4. Пользовательское переключение синхронно обновляет состояние, текст, `aria-label`, направленную иконку и сохранённое значение.
5. Календарная ссылка и заменённые календарные действия используют закреплённый публичный экспорт календаря `shlz-ui`; ссылка объектов сохраняет свою отдельную иконку.
6. Аудит охватывает SVG пользовательских действий и навигации в `app/YiiRuntime` и активных адаптерах `rapid-pilot`. Замена выполняется только при однозначном публичном соответствии. Остальные случаи перечисляются как оставленные с причиной.
7. Срез не меняет маршруты, порядок/доступность ссылок, полномочия, прикладные ответы, БД или append-only историю.

## Проверяемые примеры

- `false` + переход «Объекты монтажа» → «Календарь»: первый и последующие кадры имеют свёрнутую ширину, календарная ссылка содержит календарную иконку.
- `true` + тот же переход: меню раскрыто сразу.
- исключение при чтении `localStorage`: страница загружается с раскрытым меню.
- отключённый JavaScript: все разрешённые серверные ссылки видимы и доступны.
- повторные GET тех же страниц не создают фактов.

## Вне среза

Новый SPA-router, изменение доменной навигации, добавление новых иконок в `shlz-ui`, редизайн логотипа и декоративной графики, а также приблизительная замена иконок без публичного соответствия.
