# FMonitor

Контекст управления открытием, выполнением и оплатой монтажных работ на объектах лифтового оборудования.

## Объект и работы

**Объект монтажа**:
Конкретный лифт с регистрационным номером, адресом, договорными сроками и плановой стоимостью монтажа.
_Избегать_: строка, адрес

**Монтажное дело**:
Один процесс выполнения монтажных работ по объекту от подготовки открытия до закрытия и расчёта.
_Избегать_: новая строка, версия объекта

**Открытие работ**:
Подтверждённый сотрудником ФКР переход монтажного дела к выполнению с обязательной фиксацией фактической даты начала после прохождения проверок; в пилоте может временно опираться на подготовленный проект до регистрации распоряжения в 1С ДО.
_Избегать_: заполнение даты начала, активация строки

**Фактическая дата начала работ**:
Указанная сотрудником ФКР календарная дата, с которой монтаж действительно выполняется по заказу.
_Избегать_: плановая дата, время нажатия кнопки

## Люди и основания

**Монтажник**:
Работник, который может быть допущен к выполнению монтажных работ на основании действующего распоряжения и кадрового статуса.
_Избегать_: значение справочника, исполнитель в слоте

**Кадровый статус**:
Действующее на конкретный момент состояние трудовых отношений и доступности работника, полученное из кадровой системы.
_Избегать_: активен, флаг работает

**Каталог трудоустроенных монтажников**:
Полученный из кадрового контура перечень работников, из которого сотрудник ФКР может выбирать кандидатов для закрепления.
_Избегать_: произвольный список, ручной справочник

**Распоряжение о закреплении**:
Неизменяемый после выпуска документ по одному заказу, задающий интервал и состав допущенных исполнителей соответствующего монтажного дела.
_Избегать_: список монтажников, поле монтажник

**Подготовленное распоряжение**:
Сформированный FMonitor проект документа с зафиксированным составом, ещё не получивший регистрационный номер в 1С ДО.
_Избегать_: выпущенное распоряжение, действующее распоряжение

**Зарегистрированное распоряжение**:
Распоряжение с датой, зафиксированной FMonitor при формировании, которое впоследствии получило регистрационный номер в 1С ДО; оно является окончательным основанием назначений.
_Избегать_: проект, файл из FMonitor

**Изменяющее распоряжение**:
Новое распоряжение, прекращающее или добавляющее назначения с указанного момента без переписывания предыдущего документа.
_Избегать_: редактирование распоряжения, замена в строке

**Инженер строительного контроля**:
Пользователь FMonitor, которого сотрудник ФКР обязательно закрепляет за заказом при формировании распоряжения для контроля монтажных работ.
_Избегать_: прораб, произвольное ФИО, ответственный в свободном поле

**Форма организации труда**:
Производная характеристика состава: индивидуальная при одном закреплённом монтажнике, бригадная при нескольких.
_Избегать_: ручной переключатель, формат отчёта

**Назначение**:
Ограниченная временем связь сотрудника с монтажным делом, окончательно подтверждаемая зарегистрированным распоряжением.
_Избегать_: слот монтажника

**Заявленный состав**:
Состав исполнителей, сообщённый подрядчиком и зарегистрированный офисным координатором; сам по себе не является подтверждением присутствия.
_Избегать_: фактический состав

**Наблюдаемый состав**:
Состав исполнителей, лично зафиксированный инженером строительного контроля при инспекции.
_Избегать_: список со слов подрядчика

## Контроль и расчёт

**Инспекция**:
Датированное свидетельство инженера о прогрессе, наблюдаемом составе и приложенных материалах при посещении объекта.
_Избегать_: обновление процента

**Срез расчёта**:
Воспроизводимый набор версий фактов и правил, зафиксированный для расчёта премии на выбранную дату.
_Избегать_: выгрузка, текущая таблица

**Нарушение**:
Выявленное системой или контролёром несоответствие, которое требует решения и может блокировать открытие, выполнение или расчёт.
_Избегать_: предупреждение, красная ячейка

**Управляемое исключение**:
Ограниченное по сроку и полномочиям разрешение выполнить переход без обычного предусловия с обязательными причиной, владельцем риска и аудитом.
_Избегать_: обход, временно разрешить всем
