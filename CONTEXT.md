# FMonitor

Контекст управления открытием, выполнением и оплатой монтажных работ на объектах лифтового оборудования.

## Объект и работы

**Объект монтажа**:
Конкретный лифт с регистрационным номером, адресом, договорными сроками и плановой стоимостью монтажа.
Это процессная сущность, для которой ведётся монтажное дело и формируются распоряжения.
_Избегать_: заказ, строка, адрес

**Монтажное дело**:
Один процесс выполнения монтажных работ по объекту от подготовки открытия до закрытия и расчёта.
_Избегать_: новая строка, версия объекта

**Открытие работ**:
Подтверждённый сотрудником ФКР переход монтажного дела к выполнению с обязательной фиксацией фактической даты начала после прохождения проверок; переход разрешён только по распоряжению в статусе «Зарегистрировано в 1С ДО».
_Избегать_: заполнение даты начала, активация строки

**Фактическая дата начала работ**:
Указанная сотрудником ФКР календарная дата, с которой монтаж действительно выполняется на объекте монтажа.
_Избегать_: плановая дата, время нажатия кнопки

## Люди и основания

**Роль пользователя FMonitor**:
Импортируемое из legacy FMonitor организационное назначение пользователя, которое служит основанием для набора прикладных полномочий rapid pilot; у пользователя может быть несколько ролей.
_Избегать_: право, capability, должность

**Прикладное полномочие**:
Стабильное разрешение на процессное действие или специализированный экран, полученное из всех активных ролей пользователя либо назначенное ему как явное исключение.
_Избегать_: роль, пункт меню, legacy right

**Монтажник**:
Внешний для учётных записей FMonitor работник, который может быть допущен к выполнению монтажных работ на основании действующего распоряжения и кадрового статуса. Монтажник не является пользователем FMonitor и не получает роль или процессные полномочия.
_Избегать_: пользователь FMonitor, значение справочника, исполнитель в слоте

**Кадровый статус**:
Действующее на конкретный момент состояние трудовых отношений и доступности монтажника, происходящее из кадрового первоисточника и полученное через интеграционный канал.
_Избегать_: активен, флаг работает

**Фактическая дата увольнения**:
Дата прекращения трудовых отношений, явно полученная из кадрового первоисточника. Она неизвестна, если интеграционный канал передаёт только текущее состояние.
_Избегать_: дата синхронизации, дата первого обнаружения увольнения

**Первое наблюдение увольнения**:
Момент, когда FMonitor впервые получил состояние «уволен»; это свидетельство времени обнаружения, а не фактическая дата увольнения.
_Избегать_: дата увольнения, кадровая дата

**Каталог трудоустроенных монтажников**:
Полученный из кадрового контура перечень работников, из которого сотрудник ФКР может выбирать кандидатов для закрепления.
_Избегать_: произвольный список, ручной справочник

**Распоряжение о закреплении**:
Неизменяемый после выпуска документ по одному объекту монтажа, задающий интервал и состав допущенных исполнителей соответствующего монтажного дела.
_Избегать_: список монтажников, поле монтажник

**Состав распоряжения**:
Один или несколько монтажников и ровно один инженер строительного контроля, закрепляемые за объектом монтажа одной версией распоряжения.
_Избегать_: монтажники и инженер, состав или инженер, список монтажников

**Подготовленное распоряжение**:
Сформированный FMonitor проект документа с зафиксированным составом, ещё не получивший регистрационный номер в 1С ДО.
_Избегать_: выпущенное распоряжение, действующее распоряжение

**Зарегистрированное распоряжение**:
Распоряжение с датой, зафиксированной FMonitor при формировании, которое впоследствии получило регистрационный номер в 1С ДО; оно является окончательным основанием назначений.
_Избегать_: проект, файл из FMonitor

**Изменяющее распоряжение**:
Новое распоряжение, прекращающее или добавляющее назначения с указанного момента без переписывания предыдущего документа.
_Избегать_: редактирование распоряжения, замена в строке

**Инженер строительного контроля**:
Пользователь FMonitor, входящий в состав распоряжения и закрепляемый сотрудником ФКР за объектом монтажа для контроля монтажных работ.
_Избегать_: прораб, произвольное ФИО, ответственный в свободном поле

**Системный администратор**:
Пользователь с правом управлять техническим доступом и просматривать security-аудит; это право не позволяет выполнять процессные команды ФКР или исправлять исторические факты.
_Избегать_: сотрудник ФКР, процессный администратор, суперпользователь без ограничений

**Форма организации труда**:
Производная характеристика состава: индивидуальная при одном закреплённом монтажнике, бригадная при нескольких.
_Избегать_: ручной переключатель, формат отчёта

**Назначение**:
Ограниченная временем связь сотрудника с монтажным делом, окончательно подтверждаемая зарегистрированным распоряжением.
_Избегать_: слот монтажника

**Монтажная организация**:
Организация, которая в определённом монтажном деле выполняет монтажные работы; роль организации в деле может быть подтверждена договорным или иным организационным основанием.
_Избегать_: строка подрядчика, работодатель без основания, постоянный тип организации

**Статус идентификации монтажной организации**:
Оценка достаточности доказательств для сопоставления legacy-наименования с конкретным юридическим лицом: «надёжно» разрешает использовать подтверждённый налоговый идентификатор, «требует уточнения» сохраняет исходное обозначение без назначения юридических реквизитов до отдельного подтверждения.
_Избегать_: вероятность совпадения, автоматически угаданный ИНН, признак активности организации

**Принадлежность монтажника к монтажной организации**:
Ограниченная временем подтверждённая связь монтажника с монтажной организацией, имеющая источник и основание; она не следует автоматически из совместного присутствия монтажника и организации на одном объекте.
_Избегать_: поле субподрядчик у монтажника, текущая компания навсегда, вывод по одному объекту

**Заявленный состав**:
Состав исполнителей, сообщённый подрядчиком и зарегистрированный офисным координатором; сам по себе не является подтверждением присутствия.
_Избегать_: фактический состав

**Наблюдаемый состав**:
Состав исполнителей, лично зафиксированный инженером строительного контроля при инспекции.
_Избегать_: список со слов подрядчика

## Контроль и расчёт

**Инспекция**:
Датированное свидетельство инженера о прогрессе, наблюдаемом составе и приложенных материалах при посещении объекта.
_Избегать_: обновление процента

**Снимок чек-листа**:
Неизменяемые для монтажного дела разделы, пункты, порядок и веса применимой версии чек-листа, зафиксированные при открытии работ.
_Избегать_: текущий глобальный справочник, редактируемый список этапов

**Факт выполнения пункта**:
Датированное свидетельство закреплённого инженера строительного контроля о выполнении конкретного пункта снимка чек-листа; последующее исправление дополняет историю и не удаляет исходный факт.
_Избегать_: чекбокс, текущее значение процента, редактирование выполненной работы

**Фото раздела**:
Доказательный материал, приложенный инженером строительного контроля к разделу снимка чек-листа; наличие минимум одного актуального фото обязательно для завершения раздела.
_Избегать_: фотография всего объекта без контекста, файл чек-листа

**Локально сохраненная операция**:
Действие стройконтроля, надёжно сохранённое на его устройстве при нестабильной связи, но ещё не принятое FMonitor как подтверждённый серверный факт.
_Избегать_: выполнено, синхронизировано, подтверждено сервером

**Завершение раздела чек-листа**:
Отдельный факт стройконтроля о готовности раздела, допустимый после выполнения всех его пунктов и приложения минимум одного актуального фото; вес прогресса при этом повторно не начисляется.
_Избегать_: отметить всё, выставить процент раздела

**Срез расчёта**:
Воспроизводимый набор версий фактов и правил, зафиксированный для расчёта премии на выбранную дату.
_Избегать_: выгрузка, текущая таблица

**Нарушение**:
Выявленное системой или контролёром несоответствие, которое требует решения и может блокировать открытие, выполнение или расчёт.
_Избегать_: предупреждение, красная ячейка

**Управляемое исключение**:
Ограниченное по сроку и полномочиям разрешение выполнить переход без обычного предусловия с обязательными причиной, владельцем риска и аудитом.
_Избегать_: обход, временно разрешить всем
