# Owner decision — installation completion

Date: 2026-09-02  
Status: **APPROVED**

Владелец продукта подтвердил:

- ошибочно внесённая дата акта ПТО или декларации исправляется новым
  append-only фактом с обязательной причиной;
- исходный факт сохраняется навсегда и не изменяется/не удаляется;
- декларация обязательна для завершения монтажного дела;
- целевая доменная модель прогресса: checklist даёт первые 85%, а документы
  закрывают последние 15%; это не временный pilot shortcut.

Фраза владельца «БТО» интерпретирована как очевидная опечатка в «ПТО» в
контексте заданного вопроса и всей принятой терминологии репозитория.

Решение снимает GRILL-001 вопросы 2–3 в части completion model, correction и
обязательности декларации. Exact authorization capabilities и состав полей
документального evidence остаются предметом отдельных executable behavior
specs; schema ownership не должно выдавать текущий authenticated-only adapter
за утверждённую authorization policy.
