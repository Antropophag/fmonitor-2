# Демонстрация минимального операционного дашборда

1. Войти пользователем с полномочием `objects.read` и открыть `/pilot/dashboard`.
2. Назвать показанную дату «Срез на»: это единая московская календарная дата запроса.
3. Пояснить четыре числа: «Всего объектов» — доступный реестр; «В активном монтаже» — монтажные работы и документарное закрытие; «Просрочены» — незавершённые объекты со сроком раньше среза; «Начало в ближайшие 14 дней» — старт от даты среза по тринадцатый день включительно.
4. Перейти из списка к одному просроченному или ближайшему объекту, затем вернуться по ссылке «Перейти к реестру объектов».

Это будущие идеи, а не реализованные обещания: текущая версия не содержит графиков, произвольных периодов, персонализации или финансовых показателей.
