# Решение владельца: журнал каждой отклонённой попытки

Дата: 2026-09-06. Автор записи: `/root`.

Пользователю задан вопрос простыми словами: «Если пользователь несколько раз повторяет действие, на которое у него нет прав, записывать в журнал каждый отказ или только первый?»

После запроса рекомендации предложено записывать **каждый отказ отдельно**: кто, когда и какое действие пытался выполнить. На вопрос «Утверждаешь запись каждой попытки?» пользователь ответил точно: **«утверждаю»**.

Утверждённая политика: каждая попытка действия, отклонённая из-за отсутствия прав, создаёт отдельный append-only факт аудита, включая повтор того же request ID и причины. Дедупликация этих отказов по request/reason не соответствует решению. Возможная группировка на экране не удаляет исходные факты и не входит в текущий обязательный пакет.

Решение закрывает отложенный вопрос cardinality из handoff 2026-09-06-0830Z. Оно не является техническим Gate1/Gate3/Gate5 или доказательством реализации. Последующие спецификация, миграция при необходимости, RED и независимые ревью сохраняют обязательные gates. Повторное owner approval этой политики не требуется.
