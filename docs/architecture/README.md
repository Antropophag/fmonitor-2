## Что изменилось после независимого аудита

#42 уже закрыта через #47: `.env` → контейнерная подготовка → штатный worker;
legacy exporter и host PHP удалены. По более новому решению владельца Bitrix
входит в обычный `make up`, поэтому прежнее требование независимого аудита
сохранить normal up без синхронизации больше не действует.

Сами исходные отчёты не переписываются под новый main. Подтверждения,
опровержения и актуальная очередь находятся в отдельной сверке.
Промышленная готовность и наличие повреждённых данных из этих отчётов не следуют.

## Почему документы находятся в Git

Это производные технические выводы по исходникам и бэклогу, полезные для #18/#32,
с указанными источниками и ограничениями. Реальные вебхуки, пароли, private keys,
выгрузки БД и исходные рабочие документы в этих двух текстах не обнаружены.
Поэтому добавлять отчёты в `.gitignore` оснований нет. Первичные данные и секреты
по-прежнему должны храниться вне репозитория.

Контроль сохранности предоставленных файлов (SHA-256):

- `audit-and-target-2026-09-07.md`: `e3e0ed06086d56e79f09dd85a3af9747823ff5de9fdb151e083d1b9686ad34e7`.
- `fmonitor-2-architecture-audit-2026-09-08.md`: `4c2439f781013a342f9f61cd73de1ac1c1ebb3ca86113fd89f2124760b96fd2b`.

В независимом отчёте сохранены также исходные Markdown hard breaks (два пробела
в конце строк метаданных). Стандартный `git diff --check` отмечает их как trailing
whitespace; это известная особенность неизменяемого импортированного текста,
а не незамеченный результат проверки новых выводов.
