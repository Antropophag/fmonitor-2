# Рабочий справочник монтажных организаций legacy FMonitor

Статус: зафиксированный аналитический контракт для последующей разработки, 29.08.2026. Не является исполняемой спецификацией поведения.

Источник: production-поле `fm_maintable.subsuplier`, справочник `fm_fields_values` (`field_id = 7`), внутренний справочник `c1_configurator.clients` и результаты исследования в [fmonitor-2-subcontractor-legal-identity-research.md](./fmonitor-2-subcontractor-legal-identity-research.md).

## Правила использования

- `Надёжно` означает, что конкретное юридическое лицо можно заводить в справочник с указанным налоговым идентификатором.
- `Требует уточнения` означает, что запись нельзя автоматически связывать с юридическим лицом или назначать ей ИНН. Кандидат, если указан, служит только для ручной сверки.
- Составная legacy-строка обозначает участие нескольких субъектов, а не вариант названия первого субъекта. Направление и вид связи из скобок не выводятся.
- Исходное значение и его `legacy_value_id` сохраняются всегда. Нормализация не должна переписывать исторический факт.
- `КП (каркас)` не является монтажной организацией и переносится как неразрешённая технологическая пометка.

## Обязательные ограничения будущей реализации

1. Автоматическое сопоставление разрешено только для строк/частей строки со статусом `Надёжно`.
2. Для неразрешённого субъекта должны сохраняться исходное имя, источник и статус `Требует уточнения`; фиктивный ИНН не создаётся.
3. Составная строка порождает отдельные упоминания субъектов, но не порождает без доказательства отношение `генподрядчик → субподрядчик`, принадлежность монтажника или аффилированность организаций.
4. Последующее подтверждение должно быть отдельным датированным решением с источником доказательства; историческая legacy-строка остаётся неизменной.
5. Этот документ задаёт исходные данные для будущей спецификации. Реализация начинается только после прохождения SSD/TDD gate 1 и утверждения исполняемой спецификации.
